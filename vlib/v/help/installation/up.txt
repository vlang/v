Update the V compiler to the latest version from https://github.com/vlang/v.

It also reports the agent skills that the new revision left behind. Skills with
local changes, and skills installed before V recorded what it installed, are
reported but left alone; `v skills update` explains that in more detail.

Usage:
  v up

Options:
  -v       Print more details about the update.
  -prod    Compile the updated V with the -prod flag.
  -skills  Refresh the installed agent skills that fell behind.
