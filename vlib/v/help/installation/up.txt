Update the V compiler to the latest version from https://github.com/vlang/v.

After updating the checkout, it skips rebuilding the compiler if its implementation
sources and dependencies have not changed since the executable's recorded revision.
Documentation and test-only changes do not trigger a rebuild. An unknown revision,
a failed source comparison, or -prod, -skip_v_self or -skip_current forces rebuilding.

It also reports the agent skills installed for this user, in ~/.agents/skills,
that the new revision left behind. Skills with local changes, and skills
installed before V recorded what it installed, are reported but left alone;
`v skills update --global` explains that in more detail.

Usage:
  v up [options]

Options:
  -v                 Print more details about the update.
  -prod              Compile the updated V with the -prod flag.
  -skills            Refresh the installed agent skills that fell behind, in
                     ~/.agents/skills, like `v skills update --global` does.
  -skip_v_self       Rebuild with make or makev.bat instead of `v self`.
  -skip_current      Recompile even when the checkout is already at the
                     revision.
  -h, -help, --help  Show this help and exit.
