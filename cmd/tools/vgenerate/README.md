# `v generate`

Generate model structs and controller stubs inside a V project:

```sh
v generate model User first_name:string age:int active:bool
v generate controller Users
```

The model generator writes `models/user.v` with an ORM table attribute and an
autogenerated serial `id` field. Supported field types are `string`, `int`, `i64`,
`bool`, and `f64`.

Field names must follow V's snake_case naming rules. Uppercase letters, invalid
identifier characters, and leading underscores in names such as `_name` are
rejected. Field names must be unique; `id` is already reserved by the generator.
Validation finishes before the output file is created.

The controller generator writes `users_controller.v` with `index` and `show`
handlers and a commented registration example. Adapt its `Context` type to the
project before registering the controller.

Both generators require a CamelCase name and refuse to overwrite existing files.
